# Week 3 - Requirement Analysis

## Project: GoStay

GoStay is a hotel booking web application inspired by platforms such as Booking, Traveloka, and Agoda. The goal is to help users search for hotels, view room information, compare prices, book rooms, and manage booking history in a simple and clear way.

## Summary

In Week 3, the team completed the main requirement analysis activities for the GoStay project. The deliverables include personas, user journey, product vision, scenarios, epics, user stories, product backlog, and feature identification.
