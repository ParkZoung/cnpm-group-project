# PROMPTS.md — Tuần 4

## 1. Prompt đọc repo
Mô tả repo hiện tại và kiểm tra cấu trúc file:
- "Bạn hãy phân tích repo hiện tại. Xác định xem đây là loại dự án gì, có mã nguồn hay chỉ là tài liệu, cấu trúc thư mục chính và các file quan trọng."

## 2. Prompt tạo REQUIREMENTS.md
Xây dựng nội dung tài liệu yêu cầu cho tuần 4:
- "Dựa trên phân tích repo và yêu cầu bài tập, tạo file REQUIREMENTS.md cho tuần 4 với Product Overview, Customer/Admin roles, MVP scope, out-of-scope list và 10–12 user stories. Bao gồm ít nhất một user story AI gợi ý phòng phù hợp theo nhu cầu. Không thay đổi code hoặc giao diện."

## 3. Prompt tạo GitHub Issues
Chuyển user stories thành nội dung GitHub Issues:
- "Dựa trên file REQUIREMENTS.md, hãy tạo nội dung GitHub Issues cho từng user story. Mỗi issue cần có: Title, User Story, Acceptance Criteria theo Given-When-Then, Task checklist, Notes for AI Agent, Priority, Difficulty. Không viết code. Chỉ tạo nội dung để tôi copy lên GitHub Issues."

## 4. Prompt review acceptance criteria
Kiểm tra lại acceptance criteria cho từng story:
- "Review các acceptance criteria trong file REQUIREMENTS.md để đảm bảo chúng theo định dạng Given-When-Then, rõ ràng và testable cho mỗi user story. Nếu cần, đề xuất chỉnh sửa nhỏ để chuẩn hóa cấu trúc."

## 5. Ghi chú chỉnh sửa nhóm
Ghi lại những điều nhóm đã chỉnh sửa sau khi AI tạo nội dung:
- Nhóm đã sửa file `REQUIREMENTS.md` để đảm bảo nội dung tiếng Việt chuẩn, sửa lỗi encoding và hoàn thiện 11 user stories với US11 là AI gợi ý phòng.
- Nhóm đã tổng hợp và chuyển hóa các user story thành 11 GitHub Issues với title, acceptance criteria, checklist, notes for AI agent, priority và difficulty.
- Nhóm đã tạo file `PROMPTS.md` để lưu lại các prompt tuần 4 sử dụng trong quá trình làm việc.
